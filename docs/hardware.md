# 硬件规格（M0.5）

本文是 3D 打印件设计、接线、供电与标定的唯一依据。固件中的关节限位、软限位默认值均引用本文数值。

## 1. 坐标与关节轴向约定

**机身坐标**：X 前、Y 左、Z 上，单位 mm / 度。

### 髋关节（Hip）

| 项目 | 定义 |
|---|---|
| 旋转轴 | **竖直轴（Z）**，舵机输出轴朝上/朝下，卧装于机身四角 |
| 足端运动 | 水平面内、沿本腿外八斜线**前后扫摆** |
| 功能 | 推蹬步进、原地转向、设定外八张角 |
| 中立位 | 外八角**前后不等**：前腿 36°、后腿 48°（见下方说明） |

髋为纯偏航（yaw）轴，**转动不改变机身高度**——这是本构型的重要特性。

### 膝关节（Knee）

| 项目 | 定义 |
|---|---|
| 旋转轴 | **水平轴，垂直于本腿所在的竖直平面** |
| 足端运动 | 竖直平面内**上抬/下放**（等效腿长伸缩） |
| 功能 | 抬脚离地、调整腿长=机身高度、差动实现俯仰/横滚 |
| 工作区 | β∈[21.3°,65.4°]（小腿与水平面夹角），对应站立高度 90~150mm；巡航 β=39.5°（H=120mm） |

**关键提醒**：前后外八角不同，膝关节轴相对机身横轴的偏角也不同（前 36°/后 48°），**支架开孔不得按统一朝向打**。

**为什么前后不对称**：中心对称的四足布局会让任意三足支撑的裕度为 0
（对角连线必过重心）。取前 36°/后 48° 可把最差三足裕度从 0 提到约 18mm，
前进效率代价 4%。推导与数据见 docs/gait_design.md §3.5。

### 腿平面方位角（从 +X 轴逆时针，度）

| 腿 | 记号 | 方位角 | 外八角 | 髋位置(机身系) |
|---|---|---|---|---|
| 左前 | FL | 36° | 36° | (+100, +60) |
| 右前 | FR | 324° | 36° | (+100, −60) |
| 左后 | RL | 132° | 48° | (−100, +60) |
| 右后 | RR | 228° | 48° | (−100, −60) |

方位角配错会让支撑多边形非凸、重心落在多边形外，机器人静态就站不稳；
校验器会检查凸性与重心内含。

腿序索引 0..3 = FL, FR, RL, RR；每腿通道索引 2i=髋、2i+1=膝。固件与仿真共用此约定。

### 大腿倾角 α

大腿自髋向外的下倾角由**支架打印形状固定**，不是舵机可控量。当前取 α=30°，确切取值由 `tools/gait_sim` 扫参确定后出打印件（见 §6）。

```
站立高度 H = L1·sin(α) + L2·sin(β)
```

## 3. 重量预算与扭矩校核

### 重量预算

| 项目 | 预估 |
|---|---|
| 8× MG996R | 440g |
| 3D 打印框架（PLA 稀疏） | 250~350g |
| 2S 锂电（2200mAh 级） | 130~160g |
| ESP32 开发板 + PCA9685 + UBEC | 90g |
| 线材、螺丝、船型开关 | 80g |
| **合计** | **990~1120g** |

上限红线 **1.2kg**。超重直接吃掉扭矩裕度：超过 1.5kg 或腿段超过 120mm 时膝关节余量降到 1.5 倍以下。

### 扭矩校核

最恶劣工况：Trot 双腿支撑 + 抬机身（膝后仰 30°）。

```
单腿载荷 = 1.2kg / 2 = 0.6kg
膝力臂   = L2·sin(30°) = 55mm
需求扭矩 = 0.6 × 5.5 = 3.3 kg·cm
MG996R   = 9.4 kg·cm @4.8V / 11 kg·cm @6V
余量     ≈ 3.3 倍（按 6V 供电）
```

髋关节：水平推力 F≈5.9N × 步幅半值 30mm ≈ 1.8 kg·cm，余量充足。

几何派生关系（改腿长或 α 时必须重算）：

```
H(β)  = L1·sin(α) + L2·sin(β)      站立高度
R(β)  = L1·cos(α) + L2·cos(β)      足端水平半径
β_cruise = asin((H_target - L1·sin(α)) / L2)
髋半摆角 Δψ = asin(stride / 2R)
```

**结论**：扭矩不是最先卡死的约束，稳定性（重心高度）才是，见 docs/gait_design.md。

## 4. 供电

### 舵机轨

**选型：Hobbywing（好盈）UBEC 10A-Car**

| 项目 | 规格 |
|---|---|
| 输入 | 2-6S 锂电（6.0~25.2V），2S 7.4V 直接可用 |
| 输出 | **6.0V**（见下方警告） |
| 电流 | 连续 **10A** / 瞬态 **15A** |
| 尺寸重量 | 45×20×16.2mm，34g（含线） |
| 外壳 | 全金属（散热优于塑料壳）、IP67 防尘 |
| 保护 | 过流 / 输出短路 / 过热 |
| 官方定位 | crawlers、trucks 等多舵机地面平台 |

选它的理由：连续 10A 覆盖本机峰值；金属外壳在 10A 持续输出时温升明显低于塑料壳
UBEC；IP67 对应 PLA 打印件与地面扬尘环境；官方定位即多舵机地面平台。

> ### ⚠️ 上电前必读：输出电压档位
>
> 本模块输出为**三档可选：6.0V / 7.4V / 8.4V**。
>
> **必须确认拨到 6.0V 档。** MG996R 上限 6V，拨到 7.4V 或 8.4V 会让 8 只舵机在数秒内烧毁。
>
> 这是物理开关，不通电也能改，比接线错误更隐蔽。**每次更换 UBEC 或电池后重新确认一次。**

| 项目 | 规格 |
|---|---|
| 母线电容 | 1000µF 电解 + 100nF 陶瓷，紧贴 PCA9685 电源脚 |
| 舵机电源线 | 16AWG 从 UBEC 输出直连 PCA9685 V+/V-，不经开发板 |

#### 电流余量校核

| 工况 | 舵机轨电流 |
|---|---|
| 站立（8 只保持） | 1.6~3.2A |
| 爬行（4 腿摆动） | 2~4A |
| **Trot（2 腿摆动，最恶劣）** | **4~6A** |
| 8 只同时堵转 | 20A |

```
正常工况合计峰值   ~6.5A（含主控轨 0.5A）
UBEC 连续 10A  → 1.54× 余量  ✓
UBEC 瞬态 15A  → 覆盖堵转瞬态  ✓
```

8 只同时堵转属于机械故障（腿卡死、机身被顶住），不属正常工况，也不应靠加大
UBEC 额定电流来解决——真堵转时 15A 与 25A 的区别只是烧得快慢，而非烧不烧。

### 主控轨

**从 2S 电池独立取电，经 DC-DC 降压后送 ESP32 的 VIN。**

| 项目 | 规格 |
|---|---|
| 电源 | 2S 电池 8.4V → **DC-DC 5.0V/1A**（MP1584EN 类，输出用电阻分压设定为 5.0V） |
| 去向 | ESP32 **VIN（5V 引脚）**，即开发板官方供电口 |
| 未来视觉板 | 预留 5V/2A（ESP32-S3 + RV1106 阶段） |
| 实际负载 | ESP32 + WiFi 约 0.5~0.8A；预留视觉板后约 2.5A |

降压模块为可调输出型，**上电前实测输出端确认 5.0V ± 0.2V**，误设成其他档位会顶坏开发板。

#### 3.3V 逻辑轨

**3.3V 由开发板板载稳压芯片产生，本项目不外部注入 3.3V。**

```
2S 电池 ──► DC-DC 5.0V ──► ESP32 VIN ──► 板载稳压 ──► 3.3V 轨 ──┬──► ESP32
                                                               └──► PCA9685 VDD
```

禁止把外部 3.3V 灌进开发板的 3.3V 引脚：该引脚是板载稳压芯片的**输出端**，
从外部回灌属于未定义行为，调试期又常同时插着 USB（5V），两条轨经二极管/通路
相互影响，故障现象随电池电量漂移、极难定位。

> **待实测项**：板载稳压芯片型号需在单腿调试时确认。若克隆板用了 ME6211C33
> （仅 500mA），WiFi 发射峰值会正好顶满导致 brownout。
> **判据：连 AP 传输数据时测 3.3V 轨最低电压，跌破 3.0V 则需改用独立 3.3V 供电。**

| 3.3V 轨负载 | 电流 |
|---|---|
| ESP32-WROOM-32（WiFi 发射峰值） | ~500mA |
| PCA9685 | ~5mA |

> **为什么不能由 6V 舵机轨降压得到 5V**：两条轨会耦合。
>
> ```
> 8 只舵机瞬时拉 6A → UBEC 输出端压降 → 6V 轨跌到 5.6V
>    → 5V 轨跟着跌 → ESP32 brownout 复位
> ```
>
> 现象是「机器人一走猛的就重启」，且现象随电池电量与地面阻力漂移，极难排查。
> 三条轨（6V 舵机 / 5V 输入 / 3.3V 逻辑）各自独立取电，互不影响。

### PCA9685 双供电

PCA9685 模块上有两条**互相独立**的供电轨：

| 引脚 | 接什么 | 作用 | 电压 |
|---|---|---|---|
| **VDD（VCC）** | ESP32 3.3V 引脚 | **芯片自身供电**：I2C 状态机、寄存器；模块自带的 10kΩ 上拉把 SDA/SCL 拉到此轨 | **3.3V** |
| **V+（VPWR）** | UBEC 10A-Car 6.0V 档 | **舵机配电轨**（芯片不使用该引脚） | **6.0V** |

按 VDD=3.3V 接的三点理由：

1. **I2C 电平天然匹配**：模块 10kΩ 上拉直接到 3.3V，不需要电平转换，
   也不需要对 ESP32 引脚过驱动。
2. **不需要 I2C 串联电阻**：原文档的 100~220Ω 串联电阻是用来吸收
   「5V 上拉灌入 3.3V 引脚」的，正是消除该问题后不再需要。
3. **PWM 输出电平随 VDD = 3.3V**，而标准舵机高电平门限约 2.0~2.5V，
   对 MG996R 足够。

#### 为什么 V+ 可以给 6V（5.5V 上限不适用于它）

NXP 数据手册的 2.3~5.5V 上限约束的是 **VDD**，不是 V+。V+ 是模块厂商额外
加的舵机供电轨，芯片完全不使用它。Adafruit 官方引脚说明原文：

> **V+** - This is an optional power pin that will supply distributed power to
> the servos. **It is not used at all by the chip.** ... You should provide
> **5-6VDC** if you are using servos.

> The VCC pin is just power for the chip itself. **The V+ pin can be as high as
> 6V even if VCC is 3.3V** (the chip is 5V safe).

因此本项目的 6.0V 舵机轨不构成芯片超压。

> ### ⚠️ 装机前必做：实测 V+ 与 VCC 是否隔离
>
> 上面的结论**只对 V+ 与 VCC 电气隔离的模块成立**。廉价克隆板常把两者在
> PCB 上直接短接，此时 6V 会灌进芯片 VDD —— 那是真正的超压，且会连带损坏
> ESP32 的 3.3V 轨。
>
> **断电状态下用万用表量V+ 与 VCC 之间的电阻**：
>
> | 测得| 判定 | 处理 |
> |---|---|---|
> | 开路（∞ 或 >1kΩ） | 已隔离 | 可用 6.0V 舵机轨 ✓ |
> | 接近 0Ω，或有 diode drop | **已短接** | **禁止接 6V**，见下 |
>
> 若量出短接，二选一：
>
> 1. 舵机轨降到 **5.0V**（此时 VCC=3.3V / V+=5.0V 仍安全）；
> 2. 拆掉 V+↔VCC 之间的 0Ω 电阻或跳线（板上有的话）。
>
> 测得结果请回填本节末尾的「实测记录」，避免换板后又要重新判断。

> ### ⚠️ VCC 与 V+ 禁止互连
>
> 两者电压不同（3.3V / 6.0V），接线时务必区分。
> Adafruit 对同类模块的原文警告：
>
> > if you mess up and **connect VCC to V+** you could damage your board!
>
> 插错线会让 6V 直接灌进 3.3V 轨上的 PCA9685 逻辑与 ESP32 引脚。

### 铁律

1. **禁止**用 ESP32 开发板 5V 引脚带舵机。
2. 舵机轨与主控轨**必须共地**。
3. 全部供电经船型开关 + 保险丝（**3A 主控轨，7.5A 舵机轨**）。
4. 电池装于下层板中央低位，压低重心。
5. UBEC 输出档位必须为 **6.0V**（见 §4 警告框），每次换件后复核。
6. **PCA9685 的 VCC 与 V+ 禁止互连**（3.3V 与 6.0V，§4 双供电小节）。
7. **禁止**用外部 3.3V 回灌开发板的 3.3V 引脚。
8. **禁止**在未实测确认 V+ 与 VCC 隔离前接 6.0V 舵机轨（§4 双供电小节有量法）。

**保险丝取值依据**：两者都只需防硬短路，不拦正常工况。

- **舵机轨 7.5A**：Trot 行走峰值已达 4~6A（§4 校核表），取 7.5A 留峰值余量，
  同时远低于 UBEC 的 10A 连续额定，短路时仍能可靠断开。
  **早前版本的 5A 低于行走峰值，会在正常行走中熔断。**
- **主控轨 3A**：DC-DC 额定 1A，实际峰值约 0.8A，取 3A 兼顾启动浪涌与短路保护。

## 5. 接线

### I2C

| PCA9685 | ESP32 |
|---|---|
| SDA | GPIO21 |
| SCL | GPIO22 |
| VCC（VDD，逻辑） | **3.3V**（取自 ESP32 的 3.3V 引脚） |
| GND | GND（与舵机共地） |
| OE | **GPIO25**（10kΩ 上拉至 3.3V，上电默认关断） |
| V+（VPWR，输出） | **6.0V**（UBEC 10A-Car 6.0V 档，走粗线） |
| A0~A15 接 | V+ |

I2C 线长 >30cm 时可另加 4.7kΩ 上拉（目标 3.3V）；模块自带的 10kΩ 上拉已
把 SDA/SCL 拉到 VDD=3.3V，短距离下无需额外电阻。**不再需要 I2C 串联电阻**——
它原本用于吸收「5V 上拉灌入 3.3V 引脚」，VDD 改为 3.3V 后该问题已消除。

> **VCC 与 V+ 电压不同，接线务必区分，禁止互连**（§4 双供电小节有完整说明）。

### 通道映射（PCA9685 16 路，用 0~7）

| 通道 | 腿 | 关节 |
|---|---|---|
| 0 | FL | 髋 |
| 1 | FL | 膝 |
| 2 | FR | 髋 |
| 3 | FR | 膝 |
| 4 | RL | 髋 |
| 5 | RL | 膝 |
| 6 | RR | 髋 |
| 7 | RR | 膝 |

通道 8~15 预留（未来夹爪/天线/尾巴舵机）。

### 舵机供电线

PCA9685 的 **V+** 走 16AWG 粗线直接来自 UBEC 10A-Car（6.0V 档）输出，
**不经过开发板**。每路舵机信号地与电源地同源，避免压降。

舵机信号线（PCA9685 的 A0~A15 输出）电平为 3.3V，随 VDD 轨；MG996R
高电平门限约 2.0~2.5V，可正常识别。

### 机械硬性要求

1. **膝轴惰侧必须用法兰轴承**，不得只靠螺丝怼塑料孔（见 docs/gait_design.md 的摩擦预算）
2. **髋轴承座双耳固定**：单耳固定会让输出轴在负载下摆动，吃掉齿隙余量
3. **仰面 resting pose**：翻倒时靠 P10 凸台平稳支撑，不摇晃、不压线缆、舵机盘不触地——调试期一定会翻车，翻车也要体面
4. **顶板走线凹槽**：任何姿态下线缆不受挤压
5. **α=30° 起步**：打印前用 gait_sim 扫 α∈[25°,35°] 确认后再改支架

### 待 gait_sim 确认后才冻结的参数

- α（大腿倾角）：候选 25°~35°（初值 30°）
- 巡航 β：候选 36°~44°（初值 39.5°，对应 H=120mm）
- L1/L2：候选 90~130mm（初值 100/110）

当前 `params.yaml` 的 `meta.freeze_status` 为 `pending_sweep`；扫参验收通过后置 `frozen`，再据此出打印件。

## 7. MG996R 标定注意

| 项目 | 说明 |
|---|---|
| 标称脉宽 | 1000~2000µs（部分批次支持 500~2500µs） |
| 差异 | 批次/仿品差异大，中位与端点需逐机实测 |
| 解决 | servo 层提供 min/max/trim/reverse 标定参数，存 NVS；Web 页可实时预览并保存 |
| 端点 | 严禁贴死端点（顶死会持续堵转发热）；留 5~10µs 余量 |
| 速度 | 0.14s/60° @6V 空载；带载显著变慢 → 步态周期下限 1.5s，servo 层设角速度上限 |

### 机械摩擦来源与对策

| 来源 | 影响 | 对策 |
|---|---|---|
| 舵机齿隙 ~0.5~1° | 足端 1~2mm 残差 | 巡航屈膝位预紧（齿隙单向贴合） |
| 支架/舵机盘柔性 | 载荷越大越明显 | 双耳固定、短悬臂、膝侧法兰轴承 |
| 标定残差 | 系统性微搓 | 逐机标定 α/L1/L2（docs/calibration.md） |
| 地面不平 | 换脚瞬间载荷转移 | 橡胶垫受控微滑吸收，优于堵转憋电流 |

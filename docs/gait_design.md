# 步态设计

本文定义 2DOF 四足的步态几何、时序、滑移预算与稳定约束。参数唯一定义源为 `tools/gait_sim/params.yaml`，本文给出推导与判据。

## 1. 2DOF 构型的能力边界

### 1.1 几何本质

2DOF 腿的足端**水平可达集是一条直线**（髋摆方向上的线段）。行走的力学要求：机身沿方向 d 平移时，每个支撑足须能沿 d 扫摆。

推论：

- 四腿扫摆线互相平行 → 只有一个平移轴
- **把髋舵机装成别的角度只是换轴，不能加轴**：全改成横向 → 能横走但不能前后走，等价于一只只会横走的螃蟹
- 需要「抬脚 + 二维落足」才能全向，这是 3DOF 的定义

### 1.2 2DOF 能做什么

| 能力 | 可行性 | 机制 |
|---|---|---|
| 前后行走 | ✓ | 髋扫摆 + 膝推蹬 |
| 原地转向 | ✓ | 髋切向扫摆，支撑足钉地 |
| 大角度转向 | ✓ | 走转向步态（依次抬脚换位），不用拧 |
| 站高/蹲低 | ✓ | 膝角直接控制，**需按摆动相变高**（§4） |
| 机身俯仰 | ✓ | 前后膝差动 |
| 机身小角度横滚 | ✓ | 左右膝差动（4 膝 > 姿态面 3 自由度） |
| 侧移（横走） | 组合 | 转向 → 直行 → 转回的软件宏（§5） |
| 精细侧位微调 | 借滑移 | 棘轮搓动（§6），限幅 ≤50mm |
| 全向（丝滑横移/斜走） | ✗ | 需 3DOF，已定案不做 |
| 翻身自复位 | ✗ | 拟真一致性（docs/insect_behavior.md） |
| 弹跳跳跃 | 一期 ✗ | 功率瓶颈；二期弹性肌腱实验 |

### 1.3 唯一的额外自由度来源

4 脚全着地时约束超定（12 约束 > 7 可控变量），必然有一处打滑。**与其让系统随机找地方搓，不如设计性地搓**——这是滑移辅助动作（§6）的物理基础，也是 2DOF 借用额外自由度的唯一途径。

## 2. 巡航姿态：α 与 β 的联合取值

站立高度：

```
H = L1·sin(α) + L2·sin(β)
```

膝角 β 转动时的运动学耦合（关键）：

```
高度变化 : 足端水平位移 = 1 : cot(β)
```

由几何 `H(β) = L1·sin(α) + L2·sin(β)`、`R(β) = L1·cos(α) + L2·cos(β)`（L1=100, L2=110, α=30）：

| β | 耦合 1:cot(β) | 站立高度 H | 足端半径 R | 评价 |
|---|---|---|---|---|
| 65.4°（软限位上限） | 1 : 0.45 | 150mm | 133mm | 腿接近伸直，齿隙双向 |
| 50° | 1 : 0.84 | 134mm | 151mm | 偏伸直 |
| **39.5°（巡航）** | **1 : 1.21** | **120mm** | **171mm** | **平衡点** |
| 30°（深蹲） | 1 : 1.73 | 105mm | 182mm | 腿软，扭矩裕度下降 |
| 21.3°（软限位下限） | 1 : 2.55 | 90mm | 189mm | 高度极灵敏 |

**决策**：巡航 β=39.5°（H=120mm），绝不设计在伸直位。三个理由：伸直位变高效率近零且强制拖脚；屈膝位舵机工作在中段扭矩与回差最优；巡航屈膝让齿隙单向贴合减少残差。

**推论**：巡航高度 120mm 不是自由选择，而是 β=39.5° 的必然结果。腿长 L1/L2 或 α 改动都会移动巡航高度，必须重算 β：

```
β_cruise = asin( (H_target - L1·sin(α)) / L2 )
```

软限位 β∈[21.3°,65.4°] 对应高度 [90,150]mm，与 `posture.height_range_mm` 一致。

α（大腿倾角，支架打印固定）候选 25°~35°，初值 30°。**α 与 β 的最终配对由 gait_sim 扫参确定**，判据：

1. 巡航高度落在 115~125mm
2. 站立高度调节范围覆盖 90~150mm
3. 全步态周期内膝角不越软限位（β∈[21.3,65.4]）
4. 抬脚高度 ≥25mm 时髋角不越限

## 3. 步态时序

### 3.1 爬行（Crawl，4 拍）

一次仅一条腿摆动，相位严格错开。

| 相位 | FL | FR | RL | RR |
|---|---|---|---|---|
| 0 | 摆动 | 支撑 | 支撑 | 支撑 |
| 1 | 支撑 | 摆动 | 支撑 | 支撑 |
| 2 | 支撑 | 支撑 | 摆动 | 支撑 |
| 3 | 支撑 | 支撑 | 支撑 | 摆动 |

每周期 4 拍，单腿占空比 0.25 摆动 / 0.75 支撑。三足支撑三角形始终存在 → 静态稳定，无横滚风险。

单腿摆动相细分（周期 P 内）：

```
0.00 ~ 0.15 P   抬起      膝角减小，髋保持
0.15 ~ 0.55 P   前摆      髋角 +Δψ，膝回到巡航位
0.55 ~ 0.70 P   落下      膝角减小
0.70 ~ 1.00 P   后蹬      髋角 -Δψ（推进），膝保持
```

### 3.2 小跑（Trot，2 拍）

对角腿同步：

| 相位 | FL | FR | RL | RR |
|---|---|---|---|---|
| 0 | 摆动 | 支撑 | 支撑 | 摆动 |
| 1 | 支撑 | 摆动 | 摆动 | 支撑 |

每周期 2 拍。双足支撑线仅两点 → **动态横滚是主要风险**（§7）。

### 3.3 速度与周期

| 项目 | 值 | 约束来源 |
|---|---|---|
| 爬行周期 | 2.0~2.5s | 996R 带载转速 + 舵机角速度上限 180°/s |
| Trot 周期 | 1.8~2.2s | 同上；支撑相需完成推蹬行程 |
| 步幅（爬行） | 60mm | 髋半摆 ±10.1° = asin(60/2/171.5) |
| 步幅（Trot） | 68mm | 髋半摆 ±11.4° |
| 巡航速度 | 35~38mm/s | 爬行 60/1.7=35.3，Trot 68/1.8=37.8 |
| 抬脚高度 | 25~40mm | 跨线缆/门槛 |

**周期下限 1.5s 是硬约束**：996R @6V 带载速度约为空载一半，指令快于机械响应会丢步抖动。servo 层角速度上限是最后一道保险。

### 3.4 转向

| 幅度 | 方式 | 说明 |
|---|---|---|
| < 25° | 支撑足钉地拧转 | 髋扫摆覆盖，支撑足不动，零滑移 |
| > 25° | 转向步态 | 依次抬脚换位；每个落点预置偏航角 |
| 侧移宏的 90° | 转向步态 | 绝不用拧；见 §5 |

转向步态实现：把目标偏航角增量分配到各腿的落点方位角，按爬行时序依次执行。落点方位角预算是 ±45°（受髋软限位约束），90° 需分两段。

## 3.5 静态稳定裕度（重要，参数扫描发现）

四足支撑多边形的最小边裕度约 174mm，看起来很稳。但**爬行是三足支撑**，
真正的判据是最差一组三足支撑的裕度，而这个值与直觉差距很大。

### 几何必然：对称布局下三足裕度为 0

中心对称的四点集（FL/FR/RL/RR 关于机身中心中心对称），任意取三只脚作支撑，
三角形必有一条边是**对角连线**，而对角连线必然穿过机身中心 —— 裕度恰为 0。
四种支撑组合全部如此：

| 支撑腿 | 临界边 | 对称布局裕度 |
|---|---|---|
| FL,FR,RL | FR–RL（对角） | 0.0 mm |
| FL,FR,RR | FL–RR（对角） | 0.0 mm |
| FL,RL,RR | FL–RR（对角） | 0.0 mm |
| FR,RL,RR | FR–RL（对角） | 0.0 mm |

这是 4 重对称的数学后果，不是参数没调好。改腿长无效：前后腿长差 ±6mm
只带来 0.1mm 的变化（对角连线方向几乎不变）。

### 可行的改善：打破前后对称

唯一有效的手段是让前后腿的外八角不同，使四足成梯形：

| 前外八 / 后外八 | 最差三足裕度 | 前进效率 cos |
|---|---|---|
| 40° / 40°（对称） | 0.0 mm | 0.77 |
| **36° / 48°（采用）** | **17.8 mm** | **0.74** |
| 34° / 52° | 25.6 mm | 0.72 |
| 28° / 64° | 52.7 mm | 0.60 |

采用 **前 36° / 后 48°**：把「刀刃上的 0mm」变成「可接受的 18mm」，
前进效率代价仅 4%。追求 50mm 需要前 28°/后 64°，代价是前进效率从 0.77
掉到 0.60 —— 后腿几乎不参与向前推，不划算。

实测全周期最小裕度：爬行 8.7mm、Trot 0.0mm。

### Trot 的静态裕度恒为 0

Trot 每次两足支撑，且**必是对角腿对**（FL+RR 或 FR+RL）。那条连线正好穿过
重心，所以 Trot 的静态裕度在每个周期都经过 0。

这不是缺陷而是几何必然：Trot 靠动态稳定。这也是以下三条防翻红线存在的
**唯一理由**，它们不可解锁：

- 默认步态为**爬行**而非 Trot
- Trot 速度上限 **70%**
- 转向角速度上限 **25°/s**

实机调参时若发现 Trot 直行易侧倾，属预期行为，不是参数错误。

### 校验方式

`tools/gen_params.py` 的 `three_leg_margin()` 计算最差三足裕度，
<15mm 报 WARN（不阻断编译）；`test_gait.c` 扫全周期取最小值断言。

## 4. 变高策略（无滑动变高）

直接站在地上屈膝会因 1:cot(β) 耦合强制足端滑动。巡航 β=39.5° 时耦合比 1:1.21，升降 30mm 伴随约 36mm 平移；β=65.4° 时虽然只有 13mm 伴随，但 dH/dβ 已降到很小、变高精度差。

**决策：变高绝不在支撑相做，走摆动相逐腿变高。**

```
高度目标 H'
for 每条腿（顺序错开，避免重心剧变）：
    该腿进入摆动相时：
        摆动起始点额外抬高 Δh → 离地
        空中调膝至 β'(H')
        落点为新巡航高度
    其余三腿支撑不动
```

结果：全程足端离地，**零滑动**。代价：变高耗时约 1 个步态周期（2~3s），可接受。

原地变高仅在标定模式保留（慢速 + 允许微滑）。

**姿态过渡也走此路径**：站起/蹲下/坐下的插值过程中若四腿同时改变 β，必然滑脚。因此姿态关键帧的插值按「抬起-调-落」分段执行，或设计成中途短暂离地的整体动作。

## 5. 侧移宏（零成本横移）

2DOF 原地转向能力完整，故横移由组合实现：

```
"左移 D mm" = 原地左转 90°（转向步态）
            → 前进步态行进 D
            → 原地右转 90° 回正（转向步态）
```

| 项目 | 值 |
|---|---|
| 总耗时 | D=100mm 时约 5~7s |
| 误差来源 | 两次转向的角度残差 + 直线航向漂移 |
| 限幅 | 单次 ≤150mm，Web 页左/右按钮或摇杆横拨触发 |
| 观感 | 略慢，但「能横着过去」的功能完备 |

**不走丝滑横移**是 2DOF 的物理边界，非实现缺陷。若频繁需要横移，应重新评估 3DOF（已定案不做）。

## 6. 滑移辅助动作（借打滑借自由度）

三类，全部**零硬件成本**，靠打破静摩擦与运动学耦合实现。

### 6.1 棘轮横移（stick-slip ratchet）

| 阶段 | 髋动作 | 摩擦状态 | 结果 |
|---|---|---|---|
| 慢相 | 左腿 +Δψ，右腿 -Δψ（相向搓动） | 静摩擦抓住 | 机身反向平移一步 |
| 快相 | 髋快速回中 | 动摩擦，脚滑 | 机身不动，脚复位 |

快慢不对称把「往复摆动」整流为「单向爬行」。行程 = 慢相膝-髋耦合产生的位移，单次 ≤50mm。

### 6.2 大角度搓动转向

类似差速滑移：左右侧腿反向扫，脚侧向打滑。用于髋行程不足的转向补足。限幅 ±10°/次。

### 6.3 姿态表情（lean）

差动膝实现横滚/俯仰，脚微滑内收外放。±10°，默认锁死在高级模式外（§7）。

### 6.4 代价与边界

| 代价 | 说明 |
|---|---|
| 脚垫磨损 | 搓动消耗橡胶 |
| 电流尖峰 | 静摩擦阶段舵机憋劲 |
| 里程误差累积 | 死算失效，不适合连续位移 |
| 噪声与抖动 | 观感不如干净步态 |
| **地面依赖** | 橡胶垫上可能搓不动（静摩擦破不掉）；太滑地面支撑相又抓不住。棘轮仅在中等摩擦面可靠 |

**定位**：微调与花式专用，不作主运动模式。`gait_sim` 摩擦模型可预览棘轮动作的滑移-抓地切换是否成立。

## 7. 足端滑移预算

### 7.1 打滑分类

| 动作 | 滑移 | 说明 |
|---|---|---|
| 爬行支撑相 | **理论零** | 关节角由「足端世界坐标固定」反解，几何闭合 |
| Trot 支撑相 | 微量（2~5mm/周期） | 对角双腿推力「平均路径」与各自理想轨迹的偏差 |
| 原地拧转（<25°） | 零 | 支撑足钉地 |
| 转向步态 | 零 | 足端移动全部发生在离地 |
| 变高（摆动相内） | **零** | §4 决策 |
| 棘轮微调 | 有意（受控） | §6 |
| 姿态过渡（若设计不当） | 必然 | 故关键帧插值须分段抬落 |

### 7.2 残差来源（物理层，设计管不到）

打滑的定义是「足端被强制相对地面移动」。设计能管到的已做到零（模型层），剩下的来自真实机器 ≠ 模型：

| 误差源 | 量级 | 对策 |
|---|---|---|
| 舵机齿隙 0.5~1° | 足端 1~2mm | 巡航屈膝位预紧，齿隙单向贴合 |
| 支架/舵机盘柔性 | 载荷越大越明显 | 双耳固定、短悬臂、膝侧法兰轴承 |
| 标定残差（模型尺寸 ≠ 实物） | 系统性微搓 | 逐机标定 α/L1/L2（docs/calibration.md） |
| 地面不平 | 换脚瞬间载荷转移 | 橡胶垫受控微滑吸收（优于堵转憋电流） |

性质：**被动的误差吸收，不是设计缺陷**。3DOF 乃至波士顿动力级机器同样存在，只是压到不可感知。此 1~3mm 与 DOF 数量无关。

### 7.3 红线

`gait_sim` 逐帧累计支撑足世界坐标偏差：

| 指标 | 红线 | 含义 |
|---|---|---|
| 支撑足滑移（爬行） | ≤3mm/周期 | 超线 → 参数或结构有问题 |
| 支撑足滑移（Trot） | ≤5mm/周期 | 同上，Trot 天然略高 |
| 模型层理论滑移 | 必须为 0 | 非 0 即代码 bug |

模型层贡献应为 0，红线只约束物理层残差。**持续超过红线 = 设计或标定出了问题**，不是 2DOF 的宿命。

## 8. 防翻约束（编译期默认锁死）

机器人无法自复位 → 翻车代价是「走过去捡它」。因此稳定性裕度是硬约束而非调优项。

| 约束 | 默认值 | 解锁方式 |
|---|---|---|
| 巡航 Trot 横滚裕度 | ≥15° | 不可解锁 |
| 转向角速度上限 | 25°/s | 不可解锁 |
| 高速步态（>70%）禁用 Trot | 强制 | 不可解锁 |
| `lean` 限幅 | ±10° | `advanced:on` |
| `nudge` 单次限幅 | ≤50mm | `advanced:on` |
| 站立高度范围 | 90~150mm | `advanced:on` |
| 速度上限 | 100% | `advanced:on` |

前三项标为不可解锁——它们是物理红线，高速 Trot 的横滚失稳概率不可接受。Web 页默认 `advanced:off`，仅串口可开（防误触）。

## 9. gait_sim 预览器的验收职责

| 验收项 | 判据 |
|---|---|
| 巡航高度 | 115~125mm |
| 高度调节范围 | 覆盖 90~150mm |
| 步幅 | 爬行 60mm，Trot 68mm |
| 巡航速度 | 35~38mm/s |
| 膝角行程 | 全周期在 [21.3°,65.4°] 内 |
| 抬脚高度 | ≥25mm 时髋角不越限 |
| 支撑足滑移 | 爬行 ≤3mm/周期，Trot ≤5mm/周期 |
| 足端离地间隙 | 摆动相全程 >0（无穿地） |
| 腿间干涉 | 四腿轨迹无重叠 |
| 参数一致性 | 与固件 `spider_params.h` 逐位一致 |

扫参清单（打印前必做）：α∈[25°,35°]、β_cruise∈[36°,44°]、L1/L2∈[90,130]mm、stride∈[45,70]mm、period∈[1.5,2.5]s。取满足全部验收项的组合，锁定后出打印件。

改动 L1/L2/α 后必须同步重算：β_cruise、足端半径 R、髋半摆角、软限位 β 区间。`params.yaml` 的 `meta.freeze_status` 在扫参完成后置 `frozen`。
